# Harmony Map

Локальное веб-приложение: психометрический тест на личность и профориентацию
(на трёх языках — казахском, русском, английском) с необязательным
экспериментальным разделом «Физиогномика» и встроенным ИИ-агентом,
который отвечает в реальном времени и обсуждает результаты.

## Что внутри

- **3 языка** (kk / ru / en), переключаются на стартовом экране — `public/js/i18n.js`
- **Тест из 54 вопросов**: 32 — черты характера (8 шкал × 4 вопроса, в духе Big Five),
  18 — профориентация по модели **RIASEC** Джона Холланда (6 направлений × 3 вопроса,
  это открытая академическая модель, **не** продукт Gallup/CliftonStrengths — важно для
  честности в статье), 4 — открытых вопроса про переломные моменты жизни
- **Физиогномика — строго по желанию**: отдельный шаг, чётко помечен как ненаучный,
  фото анализируется тем же вызовом Claude API с отдельным промптом (см. ниже)
- Оба разбора (психометрия и физиогномика) **выводятся рядом**, в одинаковой структуре
  из 5 разделов, чтобы их было легко сравнивать — то, что вы просили для проверки
  «работает ли физиогномика»
- Встроенный **ИИ-чат в реальном времени** (потоковый ответ) — знает контекст
  результатов и может их обсуждать
- **Экспорт в PDF** одной кнопкой
- Дизайн — авторская тема «измерительный прибор + карта лица»: тёмная палитра
  (чернильный синий) + латунный и стальной акценты, шрифты Unbounded / Manrope /
  JetBrains Mono (выбраны в том числе за качественную поддержку кириллицы)

## Как запустить локально

Нужен **Node.js 18 или новее**.

```bash
cd harmony-map
npm install
cp .env.example .env
```

Откройте `.env` и вставьте свой ключ Anthropic (получить на
https://console.anthropic.com/settings/keys):

```
ANTHROPIC_API_KEY=sk-ant-...
```

Затем запустите:

```bash
npm start
```

Откройте в браузере **http://localhost:3000**

Без ключа сайт откроется и по нему можно будет ходить, но экраны анализа,
физиогномики и чата покажут понятную ошибку — они реально обращаются к Claude API.

## Структура проекта

```
harmony-map/
  server.js            — Express-сервер: раздаёт фронтенд + 3 маршрута API
  prompts.js            — ПРОМПТЫ для ИИ: анализ личности, физиогномика, чат-агент
  .env                   — ваш ключ API (создайте из .env.example)
  public/
    index.html            — разметка всех экранов
    css/styles.css          — дизайн
    js/
      i18n.js                 — тексты интерфейса на 3 языках
      questions.js             — вопросы теста на 3 языках
      app.js                    — вся логика: экраны, тест, баллы, радар-диаграммы, PDF
      chat-widget.js             — чат с ИИ
```

## Что стоит доработать перед публикацией

- **Казахские переводы** (интерфейс и вопросы) — это качественный черновик, но
  перед публичным использованием стоит показать носителю языка для вычитки.
- **Промпт физиогномики** — в `prompts.js`, функция `buildPhysiognomyPrompt`.
  Он специально: (1) прямо называет практику ненаучной в начале и в конце ответа,
  (2) запрещает любые выводы о расе/этничности/поле/возрасте, (3) зеркалит структуру
  психометрического разбора для честного сравнения. Меняйте текст под себя, но
  советую сохранить эти три принципа — без них сравнение перестанет быть корректным,
  а часть выводов может стать некорректной или дискриминационной.
- **PDF** сейчас — это «снимок» экрана результатов (через html2canvas + jsPDF), а не
  текстовый PDF. Это осознанный выбор: он гарантированно правильно показывает
  казахский и русский текст без танцев с шрифтами. Если нужен именно текстовый PDF —
  можно доработать отдельно.
- **Приватность фото**: сейчас фото уходит напрямую в Claude API и нигде не
  сохраняется на сервере — это уже отражено в тексте согласия на экране 2.
- Дальше приложение легко расширять: например, сохранять историю прохождений
  в файл/базу, если вам это понадобится для статьи (сравнение по многим людям).

## Модели

По умолчанию используется `claude-sonnet-5` и для текста, и для чтения фото —
настраивается через `MODEL_MAIN` / `MODEL_VISION` в `.env`.
